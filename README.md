# Колесо Фортуны

Простая одностраничная HTML-страница с колесом фортуны в стиле рулетки.  
Подходит для розыгрышей, выбора победителя из списка имен, мини-лотерей и случайного выбора участника.

## Что умеет

- Ввод списка участников в одном поле
- Поддержка имен по одному в строке
- Поддержка вставки списка через запятую
- Визуальное колесо с цветными сегментами
- Анимация вращения
- Случайный выбор победителя
- Перемешивание списка перед запуском
- Сохранение последнего списка в браузере через `localStorage`

## Как запустить

Ничего устанавливать не нужно.

1. Открой файл [index.html](./index.html) в браузере
2. Вставь список имен
3. Нажми `Крутить колесо`

## Как использовать

Пример списка:

```text
Аня
Борис
Вика
Глеб
Даша
Егор
```

Или так:

```text
Аня, Борис, Вика, Глеб, Даша, Егор
```

Страница сама разобьет список на отдельных участников и построит колесо.

## Хранение данных

Список участников сохраняется локально в браузере через `localStorage`.

Это значит:

- После перезагрузки страницы список останется
- Никакой сервер не нужен
- Данные хранятся только на текущем устройстве и в текущем браузере
- В режиме инкогнито или в другом браузере сохранение может не работать или будет отдельным
